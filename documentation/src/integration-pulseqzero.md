# Pulseq-zero

[Pulseq-zero](https://github.com/MRsources/pulseq-zero) lets you define sequences with [PyPulseq](https://github.com/imr-framework/pypulseq) and optimize them with MR-zero, without writing `.seq` files in between.

- [README](https://github.com/MRsources/pulseq-zero/blob/main/README.md): installation, usage and examples
- [MATH.md](https://github.com/MRsources/pulseq-zero/blob/main/MATH.md): math methods used for differentiability

Examples are listed in the [Playground](playground.md).
